# data/ships

Ship types, one `.tres` file per craft: hull grid, costs, flight numbers and switches (PLAN.md sections 3.8 and 5). The six named craft are filed under the designer's names.

To add a ship, drop a file in here: it appears in the overview's ship picker with no code changes. A hull need not be a rectangle; leave spaces outside the outline for a tapered or stepped hull. `r0_ket.tres` and `p0_int.tres` are drawn from the designer's sketches; `example_ship_1` (7 by 4 spots) and `example_ship_2` (4 by 3) are placeholders.

Owner: the designer. Agents may add files named `example_*` and never change a value in an existing file.
