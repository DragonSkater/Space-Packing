# data/cargo

Cargo types, one `.tres` file per kind of cargo: shape, tags, weight and value (PLAN.md section 5).

`huge_box.tres` is the designer's 3 by 3 Huge Box for the R0-KET tutorial. Its shape is the designer's; its weight (9), value (600) and colour are starter values for the designer to replace.

Owner: the designer. Agents may add files named `example_*` and never change a value in an existing file.
